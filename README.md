## 📌 About The Project

This project is a **frontend calculator application** that performs standard arithmetic operations such as addition, subtraction, multiplication, and division.

It is built using core web technologies and focuses on **logic building, DOM manipulation, and UI design**.

Calculator apps are one of the most fundamental projects in web development, helping developers understand **event handling and JavaScript logic flow** 

---

## 🚀 Features

✨ Perform basic arithmetic operations (+, −, ×, ÷)  
🎯 Simple and user-friendly interface  
⚡ Fast and lightweight performance  
📱 Responsive design (works on mobile & desktop)  
🧠 Real-time calculation updates
